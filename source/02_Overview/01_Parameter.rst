.. _Flow Information Input File Name:

Flow Information Input File Name
------------------------------------------------------------------------------------------------------------------------


| GELATOで使用する流れの計算結果が格納されたCGNSファイルのパス。
| なお、GELATO ver2.xではソルバー起動時に表示されるダイアログから指定しているため、改めて選択を行う必要はない。(:numref:`read_cgnsfile`)

| 変更したい場合は :guilabel:`...` をクリックして表示されるダイアログから流れの計算結果のフォルダ内に含まれる :guilabel:`Case1.cgn` を選択するか、直接パスを入力する。

Delta T for Tracer Tracking
------------------------------------------------------------------------------------------------------------------------

| GELATOでトレーサー等の物質輸送解析を行う際の時間刻み。(=追跡時間間隔)
| 出力時間間隔より大きい値を入力した場合、出力時間間隔と同じ値になるようになっている。

.. note::
    | なお、追跡時間間隔は出力時間間隔を割り切れる値を入力することが望ましい。
    | 出力時間間隔内で、何回追跡計算を行うかは :guilabel:`出力時間間隔`/:guilabel:`追跡時間間隔` を四捨五入した値になるが、GELATO内での追跡は追跡時間間隔に基づいて行われるため、追跡時間間隔が出力時間間隔を割り切れない場合、出力時間間隔と追跡時間間隔が一致しないことがある。
    | 例として、出力時間間隔が5[sec]、追跡時間間隔が2[sec]の場合、出力時間間隔内で何回追跡計算を行うかは :math:`\frac{5}{2} = 2.5` を四捨五入した値である3回になり、出力時間が5[sec]の際にはトレーサーは6秒間、10[sec]の際にはトレーサーは12秒間追跡されていることになる。

Output Frequency Increase Factor
------------------------------------------------------------------------------------------------------------------------

| 読み込んだ流れの計算結果の出力間隔の中で、何回GELATOでの計算結果を出力するかを指定する。

| 例えば、Output Frequency Increase Factorが2、読み込んだ計算結果で0[sec],10[sec],20[sec]の3つのタイムステップがある場合、GELATOでの出力結果は0[sec],5[sec],10[sec],15[sec],20[sec]の5つのタイムステップとなる。

Use Original Time
------------------------------------------------------------------------------------------------------------------------

| このパラメーターを有効にした場合、GELATOで出力される計算結果の時間は流れの計算結果の時間を使用する。
| 無効の場合は読み込んだ計算結果の最初の時間に関係なく、GELATOでの計算結果の時間は0から始まる。

.. warning::
   このパラメーターを有効にした場合、以下の時間に関するパラメーターは全て読み込んだ計算結果における時間で指定する必用がある。
      - ::ref:`計算終了時間` 

Drawing Center Line
------------------------------------------------------------------------------------------------------------------------

| このパラメーターを有効にした場合、横断方向の中央を通るような縦断線が計算結果に描画される。

.. _Flow Conditions Used for Tracking:

Flow Conditions Used for Tracking
------------------------------------------------------------------------------------------------------------------------

| トレーサー等の物質輸送解析に用いる水理条件の与え方を以下の選択肢から選択する。

    (0) Use Simulated Value
        :ref:`Flow Information Input File Name` で指定された流れの計算結果から読み取った水理条件を使用する。
    (1) Give Constant Value
        水理条件として :guilabel:`Constant Velocity(m/s)` と :guilabel:`Constant Depth(m)` を与える。

一定値を与える場合に設定するパラメーター
------------------------------------------------------------------------------------------------------------------------

Constant Velocity(m/s)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

| :ref:`Flow Conditions Used for Tracking` で :guilabel:`Give Constant Value` を選択した場合、ここで指定された値を流速として使用する。

Constant Depth(m)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

| :ref:`Flow Conditions Used for Tracking` で :guilabel:`Give Constant Value` を選択した場合、ここで指定された値を水深として使用する。

Use Simulated Value
------------------------------------------------------------------------------------------------------------------------

| 以下のパラメーターは :ref:`Flow Conditions Used for Tracking` で :guilabel:`Use Simulated Value` を選択した場合に設定を行う。
| プルダウンに流れの計算結果CGNSファイルに含まれる値の名前が表示されるので、それらから選択を行う。
| 計算を行うために必須であるパラメーターの他、参考として流れの計算結果からGELATOの計算結果にコピーする値も選択することができる。

Required Result for Calculation
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

- Velocity_X(m/s)
- Velocity_Y(m/s)
- Depth(m)
- Elevation(m)

参考としてコピーするパラメーター
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

- Discharge(m3/s)
- Elevation Change(m)
- Vorticity(s-1)
- Dye Concentration

.. note::
   参考としてコピーするパラメーターについては、パラメータ名と一致しない値を選択することで、格子点の実数地の値であれば何でも参考値としてコピーすることが可能だが、CGNSにはパラメータ名で出力されるため注意が必要である。

.. _Whether to Trace The Primary Tracer:

Whether to Trace The Primary Tracer
------------------------------------------------------------------------------------------------------------------------

| トレーサーの追跡を行う場合は、有効にする。

Maximum Number of Total Tracer Particles
------------------------------------------------------------------------------------------------------------------------

| 追跡が可能な最大トレーサー数を指定する。
| 計算範囲全体のトレーサー数(動けないものを含む)がこの数に達している場合、新たなトレーサーは投入されない。

Maximum Number of Tracer Particles in one Cell
------------------------------------------------------------------------------------------------------------------------

| 1セル内に存在できる最大トレーサー数を指定する。
| 既にセル内のトレーサー数がこの値に達している場合、その後移動してきたトレーサーは除去される。

.. note::
   | 現在の仕様ではトラップによって動けなくなったトレーサーの個数もセル内の個数にカウントされるため、この値が低いとトラップ箇所で最大数に達し、移動してきたトレーサーがすべて除去されるということが発生することがある。
   | その場合はこの値を大きくすることで回避されたい。

.. _Cloning Method:

Cloning Method
------------------------------------------------------------------------------------------------------------------------

| どのような条件でトレーサーが分裂を行うか以下の選択肢より選択する。

All Empty Cells
    セル内に一つもトレーサーがないセルの中心に新たなトレーサーを発生させる。
Cells With Only one Tracer
    セル内にちょうど1つのトレーサーが存在する場合、そのトレーサーは半分の質量の2つのトレーサーに分裂する。
Specified Cells With one Tracer
    計算格子で :guilabel:`Tracer Trapping Cell` としてマッピングされているセル内において、ちょうど1つのトレーサーが存在する場合、そのトレーサーは半分の質量の2つのトレーサーに分裂する。

Maximum Cloning Generations
------------------------------------------------------------------------------------------------------------------------

| トレーサーが分割を行う際に、最大で何世代目まで分割を行うかを指定する。
| トレーサーは1世代目として新規に追加された分割が行われるたびに1ずつ世代が増加する。

Cloning Reduction Factor for Empty Cells Cloning
------------------------------------------------------------------------------------------------------------------------
| :ref:`Cloning Method` が :guilabel:`Specified Cells With one Tracer` の場合、すべての空白セルにトレーサーを発生させる際の割引係数を指定する。
| この値を2以上に設定したばあい、j方向優先でn個おきにトレーサーを発生させることができる。
| :math:`10*10` の格子において割引係数を3で設定した場合以下の画像のようにトレーサーが発生する。

.. _Whether to Trace The Trajectory Tracer:

Whether to Trace The Trajectory Tracer
------------------------------------------------------------------------------------------------------------------------
| 軌跡追跡用トレーサーの追跡を行う場合は、有効にする。

Maximum Number of Total Tracer for Trajectory
------------------------------------------------------------------------------------------------------------------------
| 軌跡追跡用トレーサーの追跡が可能な最大トレーサー数を指定する。
| 計算範囲全体のトレーサー数がこの数に達している場合、新たなトレーサーは投入されない。

Times of Tracer Trajectory Saving
------------------------------------------------------------------------------------------------------------------------
| トレーサーの軌跡を保存する最大回数(ポリラインのノード数)を指定する。
| この値を超えると軌跡の描画はその時点で停止する。
| 最大数は1,000,000回となっている。

Interval of Tracer Trajectory Saving
------------------------------------------------------------------------------------------------------------------------
| 何回トレーサーの追跡を行ったらトレーサーの現在地を軌跡ポリラインのノードとして保存するかを指定する。
| この値を小さくすると軌跡の描画が滑らかになるが、保存されるデータ量が増えるため注意が必要である。

.. note::
   | 例として3600秒間の計算を追跡時間間隔0.001秒で行った場合、保存間隔を1、最大保存回数を1,000,000にすると軌跡の保存回数は3,600,000回となり、保存最大回数を超えてしまう。
   | その場合は保存間隔の値を大きくすることで回避されたい。

.. _Fish Simulation:

Fish Simulation
------------------------------------------------------------------------------------------------------------------------
| 魚の運動のシミュレーションを行う場合に有効にする。

Periodic Boundary Condition for Fish Simulation
------------------------------------------------------------------------------------------------------------------------
| 有効にした場合、魚が上流端または下流端から流出した際に、逆側の端へ移動する。
| なお、横断方向については流出した箇所と同じ位置に流入する。

Fish Jumping
------------------------------------------------------------------------------------------------------------------------
| 有効にすると魚が跳躍をするようになる。


Fish Swimming Information List
------------------------------------------------------------------------------------------------------------------------
| 魚の運動特性リストを設定する。
| 魚の運動特性はグループ単位で設定することが可能で、グループごとに異なる特性を設定することができる。
| csvついては :ref:`Setting Parameters for Fish Simulation` を参照のこと。

.. figure:: images/01/Fish_Swimming_Information_List.png
   :width: 600pt

   : Fish Swimming Information List(リスト形式)

.. figure:: images/01/Fish_Swimming_Information_List_2.png
   :width: 100%

   : Fish Swimming Information List(表形式)


設定項目は以下の通りである。

Ratio of Fish Group
    | 魚の総数に対する各グループの魚の数を比率で指定する。
    | 魚の総数が割り切れない場合は、比率の大きい順にグループに割り振られる。
Fish Body Length (m)
    | 魚の体長を指定する。
Fish Cruise Speed (m/s)
    | 魚の通常時の巡航速度を指定する。
Fish Cruise Time (sec)
    | 魚が巡航速度で泳ぎ続ける時間を指定する。
Fish Rush Speed (m/s)
    | 魚が突進状態で泳ぐ速度を指定する。
Fish Rush Time (sec)
    | 魚が突進速度で泳ぐ時間を指定する。
Minimum Depth for Fish Activity(m)
    | 魚が問題なく泳ぐことが可能な水深を指定する。
    | この水深未満の場所での魚の挙動は :guilabel:`Fish Motion in Critical Depth Area` で指定する。
Fish Motion in Critical Depth Area
    | 魚が活動限界水深未満の場所での挙動を以下の選択肢から指定する。
    | :guilabel:`Remove` 以外の挙動の場合で通常状態の魚が移動後に活動限界水深未満の場所に移動した場合、移動の前の場所に一度戻りその後選択肢の行動をとる。
    | 移動前に水位の変化により活動限界水深未満の場所になった場合は、その場所をから選択肢の行動を行う。
    | 限界水深未満での挙動を継続中の間は移動後のに限界水深未満でもそのまま再移動等は行わない。

    Stop
        魚はその場で停止する。
    Reverse
        本来泳ぐ方向とは反対側に泳ぐ
    Noswimming
        魚は自身の遊泳能力を放棄し、流れに身を任せる。
    Random
        魚の進行方向から標準偏差を :math:`\pi /2` とする正規分布に従うランダムに傾いた方向に泳ぐ。
    Remove
        限界水深未満の場所に入った魚は除去される。
Time During Motion in Critical Depth Area(sec)
    | 限界水深未満での挙動を継続する時間を指定する。
    | この時間内では限界水深以上の位置に移動しても限界水深未満での挙動を続け、この時間を超えると通常の挙動に戻る。
Water Surface Elevation Drop Height Where Fish Consider Jumping(m)
    | 魚の跳躍が有効の時に使用されるパラメーター、魚の移動前の位置の水位と1セルi方向上流のセルとの水位差がこの値を超える場合に跳躍を行う。
Possible Jumping Height(m)
    | 魚が跳躍可能な最大水位差を指定する。
Possible Jumping Distance(m)
    | 魚が跳躍可能な最大跳躍長を指定する。
Fish Handling When Jumping Fails
    | 水位差が跳躍可能高を超えた場合の挙動を以下の選択肢から指定する。

    Stop
        魚は移動前の場所で停止する。
    Continue Swimming
        魚は遊泳を再開する。

.. note:: 
    魚の巡航と突進のサイクルについて、魚は巡航状態と突進状態をそれぞれの時間ずつ繰り返す。ただし周期をバラつかせるため、魚投入時は巡航状態から開始しその際の巡航時間は巡航時間内でのランダムな値となる。

.. note::
    魚の跳躍の条件において跳躍を行う
    - i方向に1セル上流との水位差が跳躍検討水位差を超えている 
    - 水位差が跳躍可能高以下である
    - 魚が突進状態かつ、突進状態に入ってから移動回数が2回以下である
    - 限界水深未満の挙動をしていない
    - 一番上流のセルにいない

How to Set Initial Location
------------------------------------------------------------------------------------------------------------------------
| 魚の初期位置を以下の選択肢から指定する。

Nondimensional Coordinate
    | 通常トレーサー等と同様の方法で配置を行う。
Give Total Numbers and Random Placement
    | 総個体数を与え、その個体数分の魚を格子範囲内にランダムに配置する。

Handling When Unable to Place
------------------------------------------------------------------------------------------------------------------------
| 魚が初期位置に配置できない場合の挙動を以下の選択肢から指定する。

0:Remove (Obstacle and Depth)
    | 配置される場所が障害物セルまたは活動限界水深未満の場所である場合、その魚は配置されない。
1:Remove (Obstacle)
    | 配置される場所が障害物セルである場合、その魚は配置されない。
2:Relocation (Obstacle and Depth)
    | 配置される場所が障害物セルまたは活動限界水深未満の場所である場合、その魚は別の場所にランダムで再配置される。
3:Relocation (Obstacle)
    | 配置される場所が障害物セルである場合、その魚は別の場所にランダムで再配置される。

Total Number of Fish
------------------------------------------------------------------------------------------------------------------------
| 魚をランダム配置する際の総個体数を指定する。

Initial Fish Location
------------------------------------------------------------------------------------------------------------------------
通常トレーサーの :ref:`Tracers Supply Range` と同様のため割愛する。

Fish Size Magnification Factor
------------------------------------------------------------------------------------------------------------------------
| 計算結果可視化の際に表示する魚のポリゴンのサイズを拡大するための係数を指定する。

Fish Count
------------------------------------------------------------------------------------------------------------------------
| 有効にすると、ユーザーが指定した断面iを魚が下流から上流に向けて通過した回数をカウントする。
| なお、上流から下流に向けて通過した場合はカウントが減少する。

Fish Count Section
------------------------------------------------------------------------------------------------------------------------
| 魚のカウントを行う断面のi方向のインデックスを指定する。

Fish Count Start Time(sec), End Time(sec)
------------------------------------------------------------------------------------------------------------------------
| 魚のカウントを行う期間を指定する。

| なお、拡散係数については :ref:`Random walk model considering the effect of turbulence` を参照のこと。

   :width: 600pt

Diffusivity Parameters
------------------------------------------------------------------------------------------------------------------------

| 有効にするとトレーサーのランダムウォークによる移動を行う。

拡散係数のパラメーター
------------------------------------------------------------------------------------------------------------------------

以下の式におけるaおよびbの値を指定する。

.. math:: 

    K= a \nu_t + b

Tree Drawing
------------------------------------------------------------------------------------------------------------------------
| 樹木ポリゴンの描画を行う場合は、有効にする。


Tree Drawing Condition
------------------------------------------------------------------------------------------------------------------------

| 樹木ポリゴンの描画を行う条件を以下の選択肢から指定する。

Dry Cell Only
    | :guilabel:`描画限界水深` 未満の水深のセルに樹木ポリゴンを描画する。 

Read From Cell
    | :guilabel:`描画限界水深` 未満の水深かつ、計算格子で :guilabel:`樹木繁茂セル` とマッピングしたセルに樹木ポリゴンを描画する。

Critical Depth Below Which Tree Draw(m)
------------------------------------------------------------------------------------------------------------------------
| 樹木ポリゴンを描画可能な限界の水深を指定する。
| この水深以下のセルに樹木ポリゴンが描画される。 

Average Tree Height(m)
------------------------------------------------------------------------------------------------------------------------
| 樹木ポリゴンの平均樹高を指定する。

Tree Height Variation
------------------------------------------------------------------------------------------------------------------------
| 有効にすると樹木ポリゴンの樹高を平均樹高の0.5倍から1.5倍の範囲でランダムに変動させる。

------------------------------------------------------------------------------------------------------------------------
| 描画する樹木ポリゴンの横幅に対する倍率を指定する。
| 樹木を太くしたい場合は1より大きい値を指定する。樹木の基本形は以下の画像に示すとおりである。

.. _Random Seed Value:

Random Seed Value
------------------------------------------------------------------------------------------------------------------------
| GELATO2.xから追加されたパラメーターです。
| 従来は同じ計算条件で計算した場合、同じ乱数が生成され、ランダムウォークによる移動の挙動などが何度計算しても同一となっていましたが、このパラメーターを変更することで異なる乱数を発生させ、挙動を変更することができます。
